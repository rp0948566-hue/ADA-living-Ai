🔧 DEBUGGING ISSUES

═══════════════════════════════════════════════════════════════════════════════

PROBLEM: No learning cycles starting
────────────────────────────────────────────────────────────────────────────

Checklist:
1. Is agent.py fully started?
   └─ Check console for initialization messages
   └─ Should say "Autonomous ADA Initialized"

2. Do you see "Learning Cycle #1"?
   └─ If not, autonomous system didn't start
   └─ Check for errors in console

3. Internet connection?
   └─ DuckDuckGo search requires internet
   └─ Test: ping google.com
   └─ If no internet, learning can't happen

Solution:
├─ Wait 5 seconds after starting
├─ Check console for error messages
├─ Verify internet is connected
├─ Try restarting: Kill (Ctrl+C) then python agent.py again

═══════════════════════════════════════════════════════════════════════════════

PROBLEM: Memory files not appearing
────────────────────────────────────────────────────────────────────────────

Checklist:
1. Are they created but hidden?
   └─ In file explorer, press Ctrl+H to show hidden files
   └─ Check if files exist in project folder

2. Do you have write permissions?
   └─ Right-click project folder
   └─ Properties → Security → Edit
   └─ Ensure your user has "Full Control"

3. Is first learning cycle completing?
   └─ Check console for "Memory saved"
   └─ Should appear after first cycle

Solution:
├─ Refresh folder view (F5)
├─ Check hidden files (Ctrl+H)
├─ Verify write permissions
├─ Wait 35 seconds for first cycle (30s delay + 5s processing)
├─ Look for "Memory saved" in console

═══════════════════════════════════════════════════════════════════════════════

PROBLEM: Learning is too slow / too fast
────────────────────────────────────────────────────────────────────────────

To speed up learning (30 seconds → 10 seconds):

In autonomous_ada.py, find this line:
    await asyncio.sleep(30)  # Learning interval
Change to:
    await asyncio.sleep(10)

To slow down learning (30 seconds → 60 seconds):

In autonomous_ada.py, find this line:
    await asyncio.sleep(30)  # Learning interval
Change to:
    await asyncio.sleep(60)

To learn more topics per cycle:

In autonomous_ada.py, find:
    num_topics = random.randint(1, 3)
Change to:
    num_topics = random.randint(2, 5)  # Learn more per cycle

PROBLEM: High memory usage / file sizes
────────────────────────────────────────────────────────────────────────────

PROBLEM: Voice commands not working while autonomous running

1. Autonomous is using some CPU
   └─ Reduce learning frequency

├─ Monitor Task Manager for resource usage

├─ Solution: Check file permissions if persists

"JSONDecodeError: Expecting value"
├─ Solution: JSON file was corrupted

"asyncio error: Task was destroyed"
├─ Solution: Normal on shutdown

└─ Solution: Check for race conditions if repeated
