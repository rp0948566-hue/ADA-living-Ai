🔄 WORKFLOW - HOW IT WORKS
═══════════════════════════════════════════════════════════════════════════════════

STARTUP:
  $ .\START_SYSTEM.ps1
    ↓
  [Venv created] → [Dependencies installed] → [3 terminals open]

BACKEND (Terminal 1) - Runs FOREVER every 30 seconds:
  1. Brain selects random topic
  2. Scans 10 random files
  3. Analyzes content for value
  4. Extracts important information
  5. Saves facts if confident
  6. Applies improvements
  7. Logs to learning_evolution.json
  → Result: memory/backend_intelligence.json updated

SYNC (Terminal 2) - Runs FOREVER every 15 seconds:
  1. Load backend_intelligence.json
  2. Load agent memory.json
  3. Copy both to shared_knowledge.json
  4. Merge duplicates, deduplicate
  5. Update agent.json with new facts
  6. Apply improvements to agent
  → Result: memory/shared_knowledge.json updated

AGENT (Terminal 3) - User interaction:
  1. Startup: Load shared_knowledge.json
  2. Inject knowledge into LLM instructions
  3. Listen for user input
  4. Use all available tools
  5. Send response to user
  6. Continuously receive updates from sync
  → Result: Enhanced responses with learned knowledge

  → Check: memory/memory_sync.log
  → Ensure: backend_learning_engine.py is running
  → Restart: .\START_SYNC_BRIDGE.ps1

AGENT NOT GETTING KNOWLEDGE?
  → Check: memory/shared_knowledge.json exists
  → Verify: Sync bridge is running
  → Watch: memory/memory_sync.log

MISSING FILES?
  → Run: python verify_system.py
  → Check: All imports in agent.py
  → Ensure: All workspace files present

PYTHON ERROR?
  → Activate: .\.venv\Scripts\Activate.ps1
  → Install: pip install -r requirements.txt
  → Reset: Remove-Item .\.venv -Recurse -Force
