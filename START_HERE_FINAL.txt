🎓 HOW IT LEARNS
═══════════════════════════════════════════════════════════════════════════════════

Every 30 seconds:

  1. BRAIN DECISION:
     → Brain picks random learning topic
     → Chooses from: system_optimization, code_patterns, 
        error_patterns, performance_metrics, etc.

  2. FILE SCANNING:
     → Scans 10 random Python files
     → Extracts: functions, classes, imports, comments
     → Analyzes: relevance, depth, practicality, length

  3. VALUE ANALYSIS:
     → Scores each finding (0-1)
     → Relevance: 30%
     → Technical depth: 20%
     → Practical info: 25%
     → Length: 15%
     → Uniqueness: 10%

  4. LEARNING:
     → If score > 0.3: Save to memory
     → If score >= 0.7: Apply as improvement
     → Log everything

  5. MEMORY:
     → Saves to: memory/backend_intelligence.json
     → Includes: source file, topic, score, info

RESULT:
  → Fact learned and saved permanently
  → Within 15 seconds: Synced to agent
  → Agent immediately uses new knowledge
