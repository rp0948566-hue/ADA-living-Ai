🔧 TROUBLESHOOTING

WhatsApp Not Found?
→ Install WhatsApp Desktop: https://www.whatsapp.com/download/
→ Make sure to sign in with your phone number
→ Restart the agent after installation

pyautogui Not Found?
→ Run: pip install pyautogui
→ Verify: pip show pyautogui
→ Restart your terminal

Contact Not Found?
→ Use exact contact name as it appears in WhatsApp
→ Make sure contact is saved in WhatsApp

Message Not Sending?
→ Check if WhatsApp window is active
→ Verify keyboard language is set to English
→ Check WhatsApp settings for send button (Enter vs Ctrl+Enter)

Need Help?
→ Run: python test_whatsapp_feature.py
→ Read: WHATSAPP_FEATURE_GUIDE.md
→ Check: WHATSAPP_SETUP_GUIDE.txt
