## 📊 TECHNICAL SPECIFICATIONS

### Detection Engine
- **Model**: YOLOv8 Nano
- **Input**: 640×480 RGB frames
- **Output**: Bounding boxes + confidence
- **Classes**: 80 object types
- **Threshold**: 50% confidence (adjustable)
- **Performance**: ~30 FPS effective (every 3rd frame)

### Screen Capture
- **Resolution**: Scaled to 1280×720
- **Frequency**: 2 Hz (500ms)
- **Engine**: PIL ImageGrab
- **Impact**: Low CPU (~5%)

### Threading
- **Camera**: Main GUI thread (33ms)
- **Detection**: Worker thread
- **Screen**: Capture thread
- **Queues**: Non-blocking buffers

### Memory Usage
- **Model**: ~100MB loaded
- **Detection data**: ~5-10KB per detection
- **Session**: ~1MB for 100+ detections
