🔄 HOW IT WORKS - STEP BY STEP
═══════════════════════════════════════════════════════════════════════════════════

STARTUP PHASE:
  1. Run: .\START_SYSTEM.ps1
  2. Creates virtual environment (if needed)
  3. Installs dependencies
  4. Launches 3 independent terminals
  5. Each process starts independently

TERMINAL 1 (BACKEND - Runs FOREVER):
  1. Initialize brain engine & intelligence engine
  2. [LOOP - Every 30 seconds]:
     - Brain picks random topic
     - Scan 10 random workspace files
     - Extract important information
     - Score each finding (relevance, depth, length, etc.)
     - Save if score > 0.3
     - Apply improvements if score >= 0.7
     - Log everything to memory/learning_evolution.json
  3. Every 3 cycles: Run self-improvement analysis
  4. Every 5 cycles: Update system knowledge
  5. Continue indefinitely until killed

TERMINAL 2 (SYNC - Runs FOREVER):
  1. Initialize memory sync bridge
  2. [LOOP - Every 15 seconds]:
     - Load backend intelligence
     - Load agent memory
     - Sync both to shared memory
     - Merge all knowledge sources
     - Update agent with new facts
     - Apply improvements to agent
     - Log to memory/memory_sync.log
  3. Continue indefinitely until killed

TERMINAL 3 (AGENT - User Interaction):
  1. Link all 40+ files
  2. Load merged knowledge from sync bridge
  3. Start LiveKit session
  4. Inject memory context (local + backend) into LLM
  5. Listen for user input
  6. Use all available tools
  7. Receive real-time knowledge updates
  8. Respond with enhanced intelligence
