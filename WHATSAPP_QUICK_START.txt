# WhatsApp Feature - Quick Reference Guide

## What You Can Do Now

✅ **Send WhatsApp messages** to any contact with customized tone and style
✅ **Auto-generate messages** based on AI and your preferences
✅ **Choose message tone** (formal, casual, friendly, professional, urgent, apologetic, humorous)
✅ **Select message type** (greeting, query, update, reminder, request, confirmation, apology, announcement)
✅ **Automatic tone suggestion** based on context
✅ **Fully integrated** with ADA Agent voice commands

---

## How to Use

### Via Voice Commands to ADA Agent

1. **Simple Send:**
   ```
   "Send a WhatsApp message to John saying I'm ready for the meeting"
   ```

2. **With Tone:**
   ```
   "Send a professional WhatsApp message to Mr. Smith about the project update"
   ```

3. **Generate and Send:**
   ```
   "Generate a friendly WhatsApp message about birthday wishes to Sarah and send it"
   ```

4. **Check Status:**
   ```
   "What WhatsApp tones are available?"
   "Show me the available message types"
   ```

### Via Python Code

```python
from whatsapp_sender import send_whatsapp_message

# Simple send
send_whatsapp_message(
    contact_name="John Doe",
    message="I'm ready for the meeting"
)

# Send with tone
send_whatsapp_message(
    contact_name="Mr. Smith",
    message="I wanted to discuss the project timeline",
    tone="professional",
    message_type="query",
    person_name="Mr. Smith"
)
```

|------|----------|---------|

## Installation & Setup

### 1. Install WhatsApp Desktop
- Download: https://www.whatsapp.com/download/
- Install and login to your account

### 2. Install Python Dependencies
```bash
pip install pyautogui
```

### 3. Ready to Use!
The feature is already integrated into ADA Agent. Just run it normally.

## Troubleshooting

### WhatsApp Not Found?
- Make sure WhatsApp Desktop is installed
- Restart the agent and try again

### Message Not Sending?
- Check that the contact name is exactly as it appears in WhatsApp
- Ensure WhatsApp window is accessible

### Want to Use WhatsApp Web Instead?
- The system will automatically fall back to WhatsApp Web if Desktop isn't available

## Tips & Tricks

💡 **Tip 1**: Use "quick_mode=True" if you want just the message without greeting/closing

💡 **Tip 2**: Let ADA suggest the tone - just say "Send a message about..." and it will pick the right tone

💡 **Tip 3**: You can combine tone AND message type for precise control

💡 **Tip 4**: Check available options anytime:
```
You: "What WhatsApp tones do we have?"
ADA: Shows all available tones
```
