## 📊 Detection Data Format

### What Gets Saved

```json
{
  "detection_date": "2025-01-03T12:05:30",
  "total_frames_analyzed": 150,
  
  "hand_objects": {
    "cup": [
      {"confidence": 92.5, "timestamp": "..."}
    ]
  },
  
  "object_confidence_stats": {
    "cup": {
      "average": 89.3,
      "max": 95.2,
      "detections": 5
    }
  }
}
```

### Where It's Saved

```
detection_data/
├── detections_20250103_120530.json    (All detections)
├── snapshot_20250103_120530.png       (Camera frame)
└── detection_20250103_120530.json     (Metadata)
```

## ⚙️ Key Settings

### Model Size (in object_detection_engine.py)
```python
ObjectDetector(model_size='n')  # Current: nano (fast)
# Options: 'n' (nano), 's' (small), 'm' (medium), 'l' (large), 'x' (xlarge)
```

### Confidence Threshold
```python
self.confidence_threshold = 0.5  # 0-1 (currently 50%)
# Lower = more detections, higher = stricter
```

### Detection Frequency
```python
if frame_count % 3 == 0:  # Every 3rd frame
# Change 3 to 5 = slower, 1 = faster
```

## ⚡ Performance Tips

1. **Use nano model** (default) - fastest on CPU
2. **Close other apps** - frees up resources
3. **Lower camera resolution** - if too slow
4. **Reduce detection frequency** - change from every 3rd to every 5th frame
5. **Disable screen sharing** - if not needed
