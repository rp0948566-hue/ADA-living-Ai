📱 WHATSAPP COMMANDS
═══════════════════════════════════════════════════════════════════════════════

Send a Message:
  "Send message to [name] saying [message]"
  
  Example:
  "Send message to John saying hello this is a test"

Send With Auto-Open:
  "Open WhatsApp and send message to [name] saying [message]"
  
  Example:
  "Open WhatsApp and send message to Sarah saying project is complete"

Check Status:
  "Check WhatsApp status"
  "Is WhatsApp installed?"
  "Is WhatsApp running?"


🎬 SCREEN SHARING COMMANDS
═══════════════════════════════════════════════════════════════════════════════

Start Recording:
  "Start screen share"
  "Start screen recording"
  "Begin screen share"
  
  What happens:
  → Screen recording begins
  → Real-time overlay shows:
    • "Screen Sharing - ACTIVE" 
    • Timestamp
    • Duration counter
    • Frame count
    • FPS
    • Red recording border

Stop Recording:
  "Stop screen share"
  "Stop screen recording"
  "End screen share"
  
  What you get back:
  → Duration: X seconds
  → Total frames: X
  → Average FPS: X.X
  → Save location: screen_captures/

Get Status:
  "What's the screen share status?"
  "Screen share status"
  "Screen recording status"

Get Summary:
  "Get screen share summary"
  "Screen sharing summary"

💡 TIPS & TRICKS
═══════════════════════════════════════════════════════════════════════════════

✓ Contact Names:
  Use exact names as they appear in WhatsApp
  → "Send message to Johnny" (if that's the name saved)
  → NOT "Send message to John" (if saved as "Johnny")

✓ Message Content:
  Can be any text up to system limits
  → Long messages work fine
  → Special characters usually work

✓ Screen Share Quality:
  Default is 10 FPS (good balance)
  Can be changed in code if needed
  More FPS = more frames = more disk space

✓ Stop Anytime:
  Say "stop screen share" anytime to end recording
  Partial recordings are fine
  Summary is always provided

✓ Check Before Sending:
  Say "Check WhatsApp status" first
  Ensures everything is ready
  Helps catch issues early


🔍 TROUBLESHOOTING QUICK FIXES
═══════════════════════════════════════════════════════════════════════════════

Problem: "WhatsApp not found"
Fix: Install from https://www.whatsapp.com/download/

Problem: "Contact not found" 
Fix: Use exact name from WhatsApp contacts

Problem: Message didn't send
Fix: 
  1. Check contact name is correct
  2. Try "Check WhatsApp status" first
  3. Try opening WhatsApp manually
  4. Check keyboard language is English

Problem: Screen share not working
Fix:
  pip install --upgrade pillow opencv-python

Problem: Missing packages
Fix:
  pip install pyautogui psutil pillow opencv-python numpy
