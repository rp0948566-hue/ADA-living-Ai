The system automatically searches these locations:

- `C:\Program Files (x86)\WhatsApp\WhatsApp.exe`

- `%LOCALAPPDATA%\WhatsApp\app-*\WhatsApp.exe`

## 🐛 Troubleshooting Installation

### Issue: "WhatsApp not found"
```
Error: WhatsApp not found on system

Solution:
1. Install WhatsApp Desktop from https://www.whatsapp.com/download/
2. Run the installer to completion
3. Open WhatsApp and sign in
4. Restart the agent
```

### Issue: "pyautogui not found"
```
Error: No module named 'pyautogui'

Solution:
1. pip install pyautogui
2. Verify: pip show pyautogui
3. Restart Python or Jupyter kernel
```

### Issue: "Permission denied"
```
Error: Permission denied running test

Solution:
1. Right-click Command Prompt → Run as Administrator
2. Navigate to ADA-ai folder
3. Run: python test_whatsapp_feature.py
```

### Issue: "Message not sending"
```
Error: Message typed but not sending

Solution:
1. Make sure WhatsApp window is active
2. Check if Enter or Ctrl+Enter sends messages (WhatsApp settings)
3. Verify keyboard layout (should be English)
4. Try manual send to test keyboard
```

### Issue: "Contact not found"
```
Error: Can't find contact

Solution:
1. Verify contact exists in WhatsApp
2. Use exact name spelling as in WhatsApp
3. Try opening chat manually first
4. Check for special characters in name
```
