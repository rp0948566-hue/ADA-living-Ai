```python

# Capture for 30 seconds

# Stop sharing
stop_result = sharer.stop_screen_share()
print(f"Captured {stop_result['total_frames']} frames")
print(f"Duration: {stop_result['duration_seconds']}s")
```

🐛 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Issue: WhatsApp not found
Solution: Install WhatsApp Desktop from https://www.whatsapp.com/download/

Issue: Message not sending
Solution: 
  1. Manually check if contact exists in WhatsApp
  2. Try with exact contact name
  3. Check keyboard language is set to English

Issue: Screen share not capturing
Solution:
  1. Check PIL/Pillow is installed
  2. Check opencv-python is installed
  3. Try: pip install --upgrade pillow opencv-python

Issue: Overlay text not showing
Solution:
  1. Ensure numpy is installed
  2. Check opencv-python version
  3. Try: pip install --upgrade opencv-python

Issue: Frames not saved
Solution:
  1. Check write permissions in current directory
  2. Check disk space available
  3. Verify screen_captures folder was created
