
**Option 1: Run AI Agent (Full Features)**
```bash

```

- Auto-launches Advanced Vision GUI
- Full object detection tools available
- Can use voice commands

**Option 2: Run GUI Only**
```bash
python jarvis_advanced_vision.py
```
- Just the visual system
- Camera + detection
- Screen sharing
- No voice (local use only)

**Option 3: Quick Start Menu**
```bash
python quick_start_vision.py
# Or Windows:
START_VISION.bat
```

### Using the System

**1. Camera Setup**
- Click 📷 **Start Camera** button
- Camera feed appears on left panel

**2. Enable Detection**
- Click 🔍 **Enable Detection** button
- Point camera at objects or hand
- Green boxes appear around detected items
- Confidence % shows for each object

**3. Screen Sharing**
- Click 🖥️ **Start Screen Vision** button
- Your laptop screen appears on right panel
- Real-time updates every 500ms

**4. Capture Data**
- Click 📸 **Snapshot** to save frame
- Click 💾 **Save Data** to export session
- Data saved to `detection_data/` folder

### Voice Commands (With Agent)

After starting `agent.py`, you can ask:

```
"What's in my hand?"
→ System analyzes hand, responds with objects

"Start object detection"
→ Begins continuous background detection

"What objects have you detected?"
→ Shows summary of session

"Save detection data"
→ Exports all data to JSON

"Stop detection"
→ Ends detection session
```

## 🔍 WHAT THE SYSTEM DOES

### When You Ask: "What's in my hand?"

1. **Voice Recognition**: Agent hears your question
2. **Tool Activation**: Calls `detect_hand_objects()` tool
3. **Camera Capture**: Grabs current video frame
4. **AI Analysis**: YOLOv8 detects objects in hand region
5. **Confidence Check**: Verifies each detection
6. **Response Generation**: Creates natural language response
7. **Voice Output**: Speaks response back to you
8. **Data Logging**: Saves all detection data to JSON

**Example Timeline:**
```
T+0s: User asks "What's in my hand?"
T+0.2s: Camera frame captured
T+0.5s: YOLOv8 analysis complete
T+0.7s: Objects identified: cup (92%), hand (95%)
T+1.0s: "I can see a cup in your hand"
T+1.2s: Data saved to detection_data/detections_*.json
```
