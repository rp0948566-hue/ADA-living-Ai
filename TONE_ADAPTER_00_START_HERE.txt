🆘 COMMON ISSUES & SOLUTIONS

Issue 1: Import Error
  Symptom: ModuleNotFoundError: No module named 'tone_adapter'
  Solution: Run from ADA-ai directory: cd /path/to/ADA-ai && python agent.py

Issue 2: Ollama Connection Error
  Symptom: Connection refused or [Errno 111] Connection refused
  Solution: Start Ollama in separate terminal: ollama serve

Issue 3: Model Not Available
  Symptom: Error: model 'llama3.1' not found
  Solution: Pull model: ollama pull llama3.1

Issue 4: Tests Failing
  Symptom: AssertionError in test_detect_tone_*
  Solution: Ensure Ollama is running with model available

Issue 5: YAML Configuration Error
  Symptom: ModuleNotFoundError: No module named 'yaml'
  Solution: Install PyYAML: pip install pyyaml

Issue 6: Memory Directory Missing
  Symptom: FileNotFoundError: memory/tone_logs.json
  Solution: Create directory: mkdir memory

Issue 7: Slow Response
  Symptom: Response takes >10 seconds
  Solution: Use faster model: ToneConfig(model='tinyllama')

Full troubleshooting guides:
  • TONE_ADAPTER_QUICKSTART.md (section: Troubleshooting)
  • TONE_ADAPTER_INTEGRATION_CHECKLIST.py (section: Troubleshooting)
